# 旋光の同時測定

ブランク（水）と試料液を並べて同じ画像に写し、1回転で同時に測る方法。
全体が【提案】または【要検証】。

## 1. 考え方

- カメラは画像で測るので、複数の容器を同じコマに写せば、1回転で複数の cos² 曲線が同時に取れる。
- どの瞬間も、全部の容器が同じ光源角度を見ている。
- 2つの明るさを互いに対して描けば、角度を測らなくても位相差が分かる（`01-principle.md` の6節）。

## 2. 配置

`02-apparatus.md` の構成B（光源を回す）を使う。容器とカメラを固定できるので、画像内の測定領域が動かない。

```
      ┌──────────────────────┐
      │ 測定用スマホ（固定）    │
      └──────────┬───────────┘
          偏光フィルム（カメラの前）

          ┌───┐      ┌───┐
          │水 │      │試料│      平底ガラス容器（固定）
          └───┘      └───┘
      ━━━ 穴 ━━━━━━ 穴 ━━━      穴あきコピー用紙（固定）
      ────────────────────      容器を載せる台（固定）
          ══════════════════     偏光フィルム（光源側、一緒に回る）
          ┌──────────────┐
          │ 光源のスマホ   │ ← 回る（全面が白）
          └──────────────┘
            ┌──────────┐
            │  回転台   │
            └──────────┘
```

マリュスの法則の測定との違い

- 穴あきの紙は、光源の上ではなく、容器の下に固定する。穴が中心からずれているので、光源と一緒に回すと画像内で動いてしまうためである。
- 光源は全面を一様な白にし、偏光フィルムを画面全体に貼る。
- 容器の下の穴が偏光の領域、その周りの紙が基準領域になる。

## 3. 手順の案

1. 全部の容器に水を入れて1回転測る（ゼロ点）。リサージュ図形が直線になることを確かめる。
   以後、容器・紙・光源は動かさず、中身だけを替える。容器の底のひずみや画面のむらは位置と向きで決まるので、ゼロ点で差し引くにはこれが条件になる。
2. ブランク以外を試料液に替える。
3. 1回転以上測る。
4. リサージュ図形と旋光角を見る。

## 4. リサージュ図形の見え方

| 状況 | 図形 |
|---|---|
| 旋光なし | 直線 |
| 旋光あり | 楕円（旋光角が大きいほど開く） |
| 旋光角 45° | 円 |

- 右旋・左旋は、楕円を回る向きで判別する。回転台の回る向きとの組み合わせで決まるので、右旋性と分かっているショ糖で向きを確かめて設定する。

## 5. 拡張

### 多試料

- 濃度の違う容器を3〜4本並べれば、1回転で旋光角と濃度の関係まで出せる。
- 並べられる本数は、光源の大きさで決まる。光源が回っても常に白い面の上にある範囲は、画面の短辺を直径とする円の内側に限られる（POL-Q-07）。

### 色ごとの解析

- R・G・B 別に描くと、色ごとに開きの違う楕円になる。

## 6. 注意

- 容器は同じ型の平底ガラス容器をそろえる。プラスチック容器は避ける。
- 容器を載せる台の素材にも注意する（アクリルや強化ガラスは避ける）。
- 液面の形は明るさに影響するが、位相には影響しにくい見込み（POL-Q-08）。
- 旋光角の目安は `01-principle.md` の4節を参照。
- 容器の候補は `reference/containers.md` を参照。

## 7. 正確に決める量

光が容器を縦に通るので、光路長は容器の長さではなく「液の深さ」である。
正確に決める必要があるのは、液の深さと濃度の2つ。どこまで正確に決めるかは目的による。

| 目的 | 液の深さ | 濃度 |
|---|---|---|
| 旋光角が濃度に比例することを見る | 全容器で同じなら十分（絶対値は不要）。同じ型の容器に同じ体積を入れる。 | 比が正しければ足りる。 |
| 比旋光度を求めて文献値と比べる | 絶対値が必要。 | 絶対値が必要。 |
| 未知試料の濃度を求める | 全容器でそろえる。 | 濃度の分かった標準液を数本用意する。 |

### 必要な正確さの目安

- 角度の読み取り誤差が1〜2°程度の見込みなので、他はそれより小さければ十分である。
- 深さ10 cm・濃度0.2 g/mL のショ糖で約13°。深さが5 mm ずれても、影響は0.7°ほど。
- 濃度は数%の誤差なら問題ない。
- 濃度は「溶液1 mL あたりの質量」である。ショ糖20 g を水に溶かして全体を100 mL にする（水100 mL に20 g を加えるのではない）。

### 題材になる性質

- 旋光角は「光の通り道にある糖の量」で決まる。
- まっすぐな容器で水を足して薄めても、深さが増えるぶん濃度が下がるので、旋光角は変わらない。液を半分捨てれば半分になる。

### 正確でなくてよいもの

- 光源とカメラの距離、容器の置き場所、容器の太さ、明るさの絶対値。
- 同時測定では、回転の速さそのものは問わない。回転むらの影響を受けるかは推定法による（10節）。

## 8. 場所の違う複数の試料を測るときの注意

各枠の明るさを振れ幅でそろえてから位相だけを比べるので、場所による明るさの違いは消える。場所ごとに残る癖は、ゼロ点測定で差し引く。
そのうえで、次の3点に注意する。いずれも実物での確認が要る。

| 注意点 | 内容 | 対策 |
|---|---|---|
| 斜めから見ること | 中央から外れた容器は、視線が液柱の側面を通ることがある。深い容器ほど影響が大きい。 | カメラを高くし、容器を中央に寄せる（`02-apparatus.md` の8節、POL-Q-17）。 |
| 画面のむら | 光源が回ると、穴の下を画面の違う場所が通過する。むらは主に1回転に1回の変動として現れるが、1回転に2回の成分も含みうる。 | 回転を整数回ぶん記録し、1回転に2回の成分だけを取り出す（POL-F-38）。残る分はゼロ点測定で差し引く（POL-Q-19）。 |
| 隣の光 | 容器の壁で反射した隣の光が混ざることがある。 | 容器を黒い紙の筒で囲む。 |

## 9. 枠の置き方

- 基準の枠は、穴のない紙の部分に1つ置く。
- ブランクと試料の枠は、穴より一回り小さく置く（POL-F-09）。
- 試料の枠には番号を付け、濃度を入力する（POL-F-30、POL-F-36）。

## 10. 旋光角の推定法と誤差

推定法は POL-Q-21 で決める。候補は次の3つ。

| 推定法 | 回転むら | 画素値の非線形 | 必要なもの |
|---|---|---|---|
| 時間波形への正弦波の当てはめ | 影響を受ける | 影響を受けない | 等速回転 |
| リサージュ図形の符号付き面積 | 影響を受けない | 影響を受ける | ガンマ補正 |
| 角度軸での1回転に2回の成分の位相 | 影響を受けない | 影響を受けない | 回転する側に、カメラから見える印 |

### 符号付き面積

- 図形を1周する面積は π·Ax·Ay·sin 2α になる（Ax、Ay は振れ幅の半分）。
- sin 2α から求めるので、小さい角でも感度が落ちない。符号から回る向き（右旋・左旋）も分かる。
- 面積だけで決まるのは、α が ±45° の範囲。
- 楕円の式から cos 2α を読む方法は、小さい角で感度がほぼ0になるので使わない。

### 非線形との関係

- ブランクと試料に同じ非線形がかかっても、θ 方向のずらしは保たれる。1回転に2回の成分の位相だけを見る方法は、ガンマ補正をしなくても正しい位相差を返す。
- そのため、推定法によっては M2 でガンマ補正が要らない（POL-F-03）。

### 角度軸の印

- M2 では紙が固定なので、印は回転する側（回転台の縁、光源のスマホの縁など）に付け、紙の外でカメラに写るようにする（POL-Q-09）。

### 誤差の見積もり

- 1回転600コマ、雑音が振れ幅の1%程度なら、統計による誤差は0.1°を大きく下回る見込み。
- ±1°（POL-N-03）を決めるのは系統誤差である。基準に残る偏光（`01-principle.md` の2.1節）、画面のむら（8節）、斜めから見る影響（8節）、容器がこれに当たる。
- 検証の手間はこれらに集中させる。
