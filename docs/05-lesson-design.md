# 授業での使い方

全体が【提案】。装置の検証と実践を経て書き換える。

## 1. 物理：偏光

1. 偏光フィルムを貼った光源に、もう1枚の偏光フィルムをかざして回し、明るさが変わることを目で確かめる。
2. 装置を組み、1回転させてグラフを描かせる。
3. グラフの形を言葉で表す（山がいくつあるか、どの角度で最も暗いか）。
4. 横軸を変えた表示で、関係を確かめる。

## 2. 化学：旋光

1. 全部の容器に水を入れて測り、図形を確かめる。
2. 濃度の違うショ糖水溶液を入れて測る。
3. 図形の違いを比べる。
4. 旋光角と濃度の関係をグラフにする。
5. 色ごとの結果を比べる。

## 3. 発展

- 光源側の偏光フィルムを外して、いろいろな画面を測る。回して明暗が出る画面と出ない画面があることを調べる。
- 机や水面の反射光を、角度を変えて測る（反射光の偏光）。
- 果糖など、向きの異なる物質と比べる。

## 4. 準備物

| 分野 | 準備物 |
|---|---|
| 共通 | 偏光フィルム（光源用とカメラ用の2枚）、穴あきのコピー用紙、光源にする端末、測定用スマホ |
| 構成A | 筒（紙筒や塩ビ管）、カメラ穴を開けた厚紙 |
| 構成B | 回転台、段ボール箱（遮光と台を兼ねる） |
| 旋光 | 同じ型の平底ガラス容器、ショ糖、水、はかり、体積を測る器具、黒い紙（容器を囲む筒） |

## 5. 生徒に見出させたいこと（教師用）

画面には出さない。

- 1回転で明るさの山が2つ現れること。
- 明るさが角度の cos² に比例すること。
- 糖の溶液を入れると、最も暗くなる向きがずれること。
- ずれの大きさが濃度に比例すること。
- 色によってずれの大きさが違うこと。
