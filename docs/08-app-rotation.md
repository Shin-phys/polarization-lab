# 旋光（M2）の本体：初版

`app/rotation.html` の使い方と、仕様との対応。
全体が【提案】。実機と実物で確かめて書き換える。

## 1. 構成

| ファイル | 内容 |
|---|---|
| `app/rotation.html` | 画面と操作。カメラ、枠、測定、結果、記録一覧と濃度のグラフ |
| `app/pol-analysis.js` | 解析。`tools/analyze.py` と同じ手順で計算する。Node でも読み込めるので、単体で確かめられる |
| `kit/video-file.js` | 撮影済みの動画ファイルを、カメラの代わりに読み込む部分（記録ページと共用） |

- ビルドの要らない構成で書いた（技術構成の POL-Q-14 を決めたものではない）。
- 光源のスマホでは、検証キットの光源ページ（`kit/light.html`）を開く。

## 2. 使い方

1. 光源ページを開いた光源スマホを回転台に載せ、配置を組む（`04-polarimeter-mode.md` の2節）。
2. `app/rotation.html` を開き、カメラを開始する。固定できる端末では「露出・ピント・色を固定」を押す。
3. 枠を3種類置く。ブランク（水）と試料は穴より一回り小さく、基準は黒い底から離れた白い紙の上に置く。
4. 全部の容器に水を入れて回し、「測定開始」。2回転で自動的に止まる。「この結果をゼロ点にする」を押す。
5. 容器・紙・光源を動かさず、試料の容器の中身だけを替えて、もう一度測る。
6. 「記録一覧に加える」を押し、一覧に濃度を入力する。液の深さを入れ、「原点を通る直線を引く」を選ぶと、傾きと「傾き÷深さ」が出る。

### 動画ファイルで解析する（POL-F-42〜44）

1. 「1. 映像」で「動画ファイル」を選び、「動画を選ぶ」で動画を読み込む。最初のコマが表示される。
2. 枠を置き、「再生して解析」。動画を最後まで再生しながら記録し、終わったら結果を出す。整数回転ぶんだけを使うので、3回転以上撮っておく。
3. ゼロ点、記録一覧、濃度のグラフ、CSV の保存は、カメラのときと同じ。

撮り方：iPhone の標準カメラでは、画面を長押しして AE/AF ロックをかける（ブラウザからは露出を固定できないので、これが露出を止める方法になる）。「設定 → カメラ」で HDR ビデオをオフにし、フォーマットを「互換性優先」（H.264）にする。HEVC の動画は、Windows の Chrome などで再生できないことがある。

- 符号は回転台の回る向きで決まる。ショ糖でマイナスと出たら、詳細設定の「符号を反転する」を選ぶ（POL-F-35）。
- 枠、ゼロ点、記録一覧、設定は端末に保存され、次に開いたときも残る（POL-F-52）。

## 3. 計算の既定値

| 項目 | 既定値 | 関係 |
|---|---|---|
| 旋光角 | 推定法 A（時間波形への当てはめ）。確認として推定法 B（符号付き面積）を緑で並べる | POL-Q-21（未決） |
| ガンマ | 2.2 で戻してから計算する | POL-F-03 |
| 基準との比 | 取る（基準の枠があるとき） | POL-Q-22（未決） |
| 振動数 | ブランクの緑から求め、全色で共通に使う | |
| 切り出し | 整数回転ぶん。1回転に1回の成分を同時に当てはめて分離する | POL-F-38 |
| 自動停止 | ブランクが4周期（2回転）進んだら止める。最長120秒 | POL-F-51 |

結果の欄には、次の注意を出す：明るさの変化が小さい（m < 0.15）、A と B の差が1°を超える、白飛び、基準の紙に残る偏光（p/m > 5%）、ゼロ点のあとで枠が動いた。

## 4. 仕様との対応

| 要件 | 対応 |
|---|---|
| POL-F-01・02・05・07〜09 | カメラ、円形の枠（基準・ブランク・試料）、R・G・B 別、白飛びと暗すぎの表示、露出・ピント・色の固定、枠の位置と大きさ |
| POL-F-30〜39 | 試料の枠を複数、波形、リサージュ図形、旋光角（A と B）、ゼロ点、符号の反転、濃度のグラフ、R・G・B 別、整数回転の切り出し、分位点による正規化 |
| POL-F-40・41 | 記録一覧の CSV、図の画像、フレームごとの生データの CSV（検証キットと同じ形式で、`tools/analyze.py` にかけられる） |
| POL-F-50〜53 | 開始と停止、自動停止、設定の保存、詳細設定（ガンマ、比、符号、最長時間、波形の色） |
| POL-N-01・04・05 | 処理はブラウザ内。見出しに結論を書かない。押しやすいボタン |

| POL-F-42〜44 | 動画ファイルの読み込み、動画内の時刻での記録、撮り方の案内 |

未対応：POL-F-54（枠の候補の自動表示）、M1（マリュスの法則）。

## 5. 開発時の確認（2026-10-19）

ヘッドレスの Chromium に疑似映像を入れ、ゼロ点の測定と試料の測定を続けて行った。

- 疑似映像の条件：1回転10秒、等速からのずれ 約17°（実測した回転台と同程度）、ガンマ2.2、容器の場所の癖 +1.0°、基準の紙に残る偏光 3%、旋光角 R 9.6°・G 12.0°・B 16.8°。
- 結果：2回転（21秒）で自動的に止まった。ゼロ点は +1.0°。ゼロ点を引いた旋光角は R 9.8°・G 12.3°・B 17.2°（B 法で G 12.4°）。
- 2〜3% 大きいのは、基準の紙に残した偏光（p/m ≈ 3%）の影響で、`01-principle.md` の2.1節の見積もりと合う。
- 解析部分は、`tools/analyze.py` の模擬データ（`--demo`）でも同じ値を返すことを確かめた。

実機（iPhone・Android）での確認はこれから。

## 6. 動画ファイルでの確認（2026-10-21）

- 5節の疑似映像を30秒（3回転）の WebM（VP9）にして読み込み、ゼロ点と試料を続けて解析した。ゼロ点は +1.0°、ゼロ点を引いた旋光角は R 9.7°・G 12.0°・B 17.0°（真の値 9.6°・12.0°・16.8°）。
- 記録ページでも同じ動画を記録し、CSV を `tools/analyze.py` にかけて同じ値を得た。CSV の条件の行に、動画ファイルの名前と時刻の取り方が残る。
- MP4（H.264）は、開発に使った Chromium が H.264 に対応していないため確かめられなかった（再生できないときの案内が出ることは確かめた）。iPhone・Android のブラウザでの確認はこれから（POL-Q-26）。
