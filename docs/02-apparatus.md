# 装置構成と角度の取り方

全体が【提案】または【要検証】。実物で確かめて書き換える。

## 1. 共通の部品

| 部品 | 内容 |
|---|---|
| 光源 | 白（または灰色）を表示した画面。タブレットか2台目のスマホ。本アプリの光源ページで表示する（POL-F-60〜65）。 |
| 光源側の偏光フィルム | 光源の画面に重ねる。ここを通った光が直線偏光になる。 |
| 検光子 | 測定用スマホのカメラに貼る偏光フィルム。 |
| 基準 | 穴あきのコピー用紙。光源側の偏光フィルムの上に載せる。 |
| 測定用スマホ | アプリを動かす。 |

偏光フィルムは1枚を切り分けて、光源側とカメラ側の2か所に使う。

### 光源側にも偏光フィルムを貼る理由

画面から出る光の偏光は、機種によって違う。

- 直線偏光のままだと、偏光サングラスの向きによって画面が真っ暗になる。その対策として4分の1波長板を重ねた機種があり、その場合は円偏光が出る。
- 有機ELの偏光板は反射防止が目的で、必須の部材ではない。偏光板をなくしたパネルを採用した機種もあり、その場合はほぼ無偏光になる。
- 画面保護フィルムが偏光を乱すこともある。

円偏光や無偏光では、検光子を回しても明るさが変わらず、何も測れない。
光源側に偏光フィルムを貼れば、画面がどの種類でも直線偏光が得られ、端末を選ばなくなる。

貼り方

- 画面が直線偏光の機種では、貼る向きで明るさが変わる。最も明るくなる向きで貼る。
- 円偏光や無偏光の機種では、向きを問わない。
- 固定の方法は POL-Q-16。

- LIMO の記事（有機ELの円偏光板の役割と、偏光板をなくす動き）

## 2. 構成A：筒式（測定用スマホを回す）

```
        ┌──────────────────────┐
        │ 測定用スマホ（画面が上） │ ← 筒ごと回す
        └──────────┬───────────┘
            偏光フィルム（カメラの前）
          │                      │
          │   筒（遮光と間隔）     │
          │                      │
      ━━━━━━━   穴   ━━━━━━━   穴あきコピー用紙
      ════════════════════════   偏光フィルム（光源側）
      ┌────────────────────────┐
      │   光源の画面（白表示）    │
      └────────────────────────┘
      ─────────── 机 ───────────
```

- 筒は高さ10 cm 前後の紙筒や塩ビ管。上にカメラ穴を開けた厚紙を貼ると、スマホが安定する。
- 筒は遮光と間隔の確保を兼ねる。
- 背面カメラが下を向くので、画面のグラフを見ながら回せる。
- 穴は中心に、基準の紙はその周りに輪の形で写る。回しても領域を追跡する必要がない。
- 角度：ジャイロ（方位角）または画像内の印。

## 3. 構成B：回転台式（光源を回す）

```
      ┌──────────────────────┐
  本  │ 測定用スマホ（固定）    │  本
  の  └──────────┬───────────┘  の
  山      偏光フィルム（カメラの前）  山
  　
  　         （試料の容器：旋光のとき）
  　
          ━━━━━   穴   ━━━━━     穴あきコピー用紙
          ══════════════════     偏光フィルム（光源側）
          ┌──────────────┐
          │ 光源のスマホ   │ ← 回る
          └──────────────┘
            ┌──────────┐
            │  回転台   │
            └──────────┘
      ─────────── 机 ───────────
```

- 光源のスマホに偏光フィルムを貼り、その上に穴あきの紙を載せ、穴を回転中心に合わせて回転台に置く。
- 測定用スマホは、本を2山積んだ上に橋渡しして、真上から見下ろす。段ボール箱をかぶせて上面の穴から見下ろす形にすれば、遮光と台を兼ねられる（8節）。
- 測定用スマホが静止しているので、画面のグラフを落ち着いて見られる。
- 手で回すより滑らかに回る。
- 角度：画像内の印、または印が1周する周期。旋光ではリサージュ図形を使い、角度を測らない。
- 旋光を測るときは、穴あきの紙を光源の上ではなく容器の下に固定する（`04-polarimeter-mode.md`）。

測定用スマホを回転台に載せる形は採らない。カメラが本体の端にあるため、回すとカメラが円を描いて動き、穴が視野の中で動き回るからである。背面カメラを下に向けると台でふさがるという問題もある。

### 手回しの回転台を使う場合

- 普通の回転台に測定用スマホを載せると、カメラが台でふさがる。
- 中央が開いたリング状の回転盤金具を選び、下に光源を入れる高さを確保する。
- 透明アクリルの天板は、それ自体が偏光を乱すことがあるので避ける。

## 4. 構成C：縦置き（参考）

- 画面を立て、スマホを画面に正対させて回す。
- 角度は加速度センサーの重力方向から求められる。ずれが積もらない。
- 治具は、段ボール箱の側面に丸穴を開け、スマホを固定した筒を差し込んで軸受けにする形になる。
- 工作も安定性も平置きに劣るので、推奨しない。

## 5. 構成の比較

| 観点 | A：筒式 | B：回転台式 | C：縦置き |
|---|---|---|---|
| 回すもの | 測定用スマホ | 光源 | 測定用スマホ |
| 追加の機材 | 筒、光源にする端末 | 回転台、光源にするスマホ、本 | 箱と筒、光源にする画面 |
| 回転の滑らかさ | 手回し | 電動で滑らか | 手回し |
| 画像内の領域 | 動かない（中心と輪） | 動かない | 動かない（中心と輪） |
| 複数試料の同時測定 | 難しい（領域が回る） | 向く | 難しい |
| 推奨 | マリュスの法則の手軽な版 | 旋光まで扱う版 | 参考 |

## 6. 角度の取り方

| 方式 | 内容 | 評価 |
|---|---|---|
| 画像内の印 | 紙に黒い印を1つ描き、画像内での印の方位を回転角とする。 | センサーが要らず、ずれが積もらない。最も確実。 |
| 等速回転の周期 | 印が1周する時間から、角度＝360°×経過時間÷周期とする。 | 回転が一定なら簡単。 |
| ジャイロ（方位角） | 角速度を積分した角度を OS から読む。 | 平置きで最も手軽。短時間で測り終える必要がある。 |
| 重力方向 | 加速度センサーから求める。 | 縦置きのときだけ使える。 |
| 斜めに設置 | 回転台を傾けて重力方向を使う。 | 30°以上の傾きが要り、光源ごと傾ける手間がある。採らない。 |
| コンパス | 磁気センサーを使う。 | 机や金具、磁石で数度以上狂う。採らない。 |
| リサージュ図形 | 旋光の同時測定で、角度そのものを使わない。 | 回転むらの影響を受けない。 |

### ジャイロについての補足

- ジャイロが出すのは角速度で、角度はそれを時間で足し合わせて求める。止まると角速度が0になるだけで、それまでの角度は保持される。途中で止めても、ゆっくり回してもよい。
- 弱点は、静止中もセンサーがわずかに0でない値を出すこと。これが積もって角度がずれる。
- 対策：測定を短時間（1回転10〜20秒）で終える。開始前に2〜3秒静止させてずれを測り、差し引く。
- cos² の山の間隔は必ず180°になる。これを使ってずれの検出と補正ができる。

## 7. 旋光測定の容器

- 同じ型の平底ガラス容器をそろえる。
- プラスチック容器は、底の内部ひずみが偏光を乱すことがあるので避ける。
- 容器を載せる台を使う場合も、内部ひずみのある素材（アクリル、強化ガラス）は避ける。
- 最初に全部の容器へ水を入れて測り、装置由来のずれを把握して差し引く。
- 候補と確認方法は `reference/containers.md` を参照。

## 8. 遮光とカメラの高さ

### 遮光

- 旋光角は明るさの大きさではなく、波形のずれ（位相）で読む。一定の外光が上乗せされても、結果は変わりにくい。
- 弱いのは、変動する外光である。照明のちらつき、人の影、容器や液面への映り込みがこれに当たる。
- 段ボール箱をかぶせて測ることを標準とする。上面にカメラ用の穴を開ければ、測定用スマホの台を兼ねられる。
- 効果は実物で確かめる（POL-Q-18）。

### カメラの高さ

- 中央から外れた容器は、カメラが斜めに見下ろす。深い容器では、視線が液柱の底ではなく側面を通ってしまう。
- カメラを高くし（目安は20 cm 以上）、容器を中央に寄せて、見込む角度を5°程度に抑える。
- 箱の高さは、この条件から決める（POL-Q-17）。
