# 開発方針と共通の設計原則

## 1. 目的

高校物理の実験用アプリとして、次の2点を満たすものを作る。

- スマホを最大限に活かす（カメラ・マイク・センサー・演算）。
- これまで手が届かなかった機能をもつ（高価な機器が必要だった、あるいは不可能だった見方を作る）。

## 2. 発想の型

既存の例（開発済み、または開発されているもの）に共通するのは「選ぶ・並べる・抜き出す」である。

| 型 | 例 | 得られること |
|---|---|---|
| 選ぶ | 特定の周波数以外をカットできるオシロスコープ | 班ごとに周波数をずらし、共鳴や干渉を全班同時に実験できる |
| 並べる | 斜方投射と自由落下の並置 | 自由落下・水平投射・斜方投射の定性的な性質を見出せる |
| 抜き出す | 色プロファイルを算出し特定波長のみ表示する干渉縞解析 | 波長ごとの干渉縞を抽出し、スケールから間隔を読んで波長を推定できる |
| 追う | トラッカー | 動画から運動を数値化できる |

本仕様書群の2アプリは、これに次の型を加えるものである。

| 型 | アプリ | 内容 |
|---|---|---|
| 時間軸で切る | 波の3つの見方 | 動画を「時刻を止める」「場所を固定する」の2通りに切る |
| センサーを掛け合わせる | 偏光ラボ | 角度と明るさを同時に取り、片方を横軸にする |

## 3. 共通の設計原則

2〜7は既存アプリの方針を踏襲した案である。本アプリ群にそのまま適用するかは、各アプリの未決事項で確認する。

1. 【決定】生徒の操作・撮影・作図を主役にする。シミュレーションは補助（サンプル、答え合わせ）にとどめる。
2. 【提案】インストール不要で、ブラウザ内で処理を完結させる。動画や写真を外部へ送信しない。
3. 【提案】各班が同時に実施できることを重視する（他班の音や光に邪魔されない、機材が安価）。
4. 【提案】画面の文言で結論を先に言わない。タブ名やガイド文は、道具の説明と操作の指示だけにする。
5. 【提案】タブレットやスマホで押しやすい大きめのボタンにする。PC・タブレットでは左に映像、右に設定を置く2カラムを基本とする。
6. 【提案】端末性能の差に配慮し、処理を軽く保つ（動画は縮小して処理する等）。
7. 【提案】精度の位置づけを明示する。精密測定ではなく「関係の形がはっきり見える」ことを目標とする。

## 4. 技術構成

未決。候補は次の2つで、アプリごとに決める。
