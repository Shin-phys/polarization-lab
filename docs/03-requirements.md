# 要件

状態タグと ID の規則は `common/spec-conventions.md` を参照。
装置の検証前なので、全項目が【提案】である。

## 1. モード

| モード | 内容 |
|---|---|
| M1 マリュスの法則 | 回転角 θ と明るさ I を同時に記録し、I-θ グラフを描く。 |
| M2 旋光 | ブランクと試料を同時に記録し、旋光角を求める。 |

## 2. 共通：映像と測定領域

| ID | 要件 |
|---|---|
| POL-F-01 | カメラのライブ映像を取得する。 |
| POL-F-02 | 画像上に円形の枠を置いて、測定領域を指定する。枠の役割は、基準（紙）、ブランク（水）、試料の3種類。M1 では基準と偏光の領域（穴）の2種類。 |
| POL-F-03 | 画素値にガンマの逆補正をかける。係数は設定で変えられる。M2 では、推定法によっては補正が要らない（`04-polarimeter-mode.md` の10節、POL-Q-21）。 |
| POL-F-04 | 偏光の領域の明るさを基準領域の明るさで割った比を、測定値とする。M2 で比を取るかは POL-Q-22 で決める。 |
| POL-F-05 | R・G・B を別々に記録し、色ごとに表示を切り替えられる。 |
| POL-F-06 | 基準領域の明るさの変動を表示する（基準として使えているか、外光が変動していないかの確認。POL-Q-01 の確認にも使う）。 |
| POL-F-07 | 白飛び、黒つぶれを検出して知らせる。白飛びのときは、光源ページの表示の明るさ（灰色の濃さ）を下げるよう案内する。端末の画面の明るさは下げない（POL-F-62）。 |
| POL-F-08 | 露出とピントを固定できる端末では固定する。 |
| POL-F-09 | 枠は位置と大きさを変えられる。ブランクと試料の枠は、穴より一回り小さく置くよう案内する（穴の縁、容器の壁、液面の反射を避けるため）。 |

## 3. 共通：角度

| ID | 要件 |
|---|---|
| POL-F-10 | 角度の取り方を選べる（画像内の印／等速回転の周期／ジャイロ）。 |
| POL-F-11 | 印方式：画像内の印の方位から回転角を求める。 |
| POL-F-12 | 周期方式：印が1周する時間から、経過時間を角度に換算する。 |
| POL-F-13 | ジャイロ方式：開始前に2〜3秒静止させてずれを測り、差し引く。 |
| POL-F-14 | cos² の山の間隔（180°）を使って、角度のずれを検出・補正する。 |

初版でどの方式を実装するかは POL-Q-04 で決める。現時点で推す構成（`../README.md` の4節）では、ジャイロ方式は使わない。

## 4. M1：マリュスの法則

| ID | 要件 |
|---|---|
| POL-F-20 | 回すと、I-θ グラフがその場で描かれる。 |
| POL-F-21 | I = a·cos²(θ − θ0) + b を当てはめ、曲線と係数を表示する。当てはめの表示は切り替えられる。 |
| POL-F-22 | 横軸を cos²θ にした表示に切り替えられる（直線になるかを見る）。 |
| POL-F-23 | 極座標の表示に切り替えられる。 |

## 5. M2：旋光

`04-polarimeter-mode.md` に詳細を書く。

| ID | 要件 |
|---|---|
| POL-F-30 | 試料の枠を複数置ける（ブランク1つと試料1つ以上）。枠には番号が付く。 |
| POL-F-31 | 全領域の明るさを同時に記録し、時間に対する波形として表示する。 |
| POL-F-32 | 横軸をブランク、縦軸を試料にしたリサージュ図形を表示する。 |
| POL-F-33 | ブランクとの位相差から旋光角を求める。推定法は POL-Q-21 で決める（候補：時間波形への正弦波の当てはめ／リサージュ図形の符号付き面積／角度軸での1回転に2回の成分。`04-polarimeter-mode.md` の10節）。 |
| POL-F-34 | ゼロ点の測定（全容器が水）を記録し、以後の結果から差し引ける。ゼロ点の測定から試料の測定まで、容器・紙・光源を動かさず中身だけを替えるよう案内する。 |
| POL-F-35 | 回転台の回る向きを設定でき、右旋・左旋を判別して表示する。 |
| POL-F-36 | 試料ごとに濃度を入力でき、旋光角と濃度のグラフを表示する。 |
| POL-F-37 | R・G・B それぞれで旋光角を求め、並べて表示する。 |
| POL-F-38 | 回転をちょうど整数回ぶん切り出し、1回転に2回の成分だけを取り出して位相を求める（光源の画面のむらは主に1回転に1回の変動として現れるので、これで分離する）。整数回の切り出しは、ブランクの波形の周期を数えて行う。むらのうち1回転に2回の成分は残るので、ゼロ点測定（POL-F-34）で差し引く。 |
| POL-F-39 | 各領域の振れ幅は、最小値・最大値ではなく、上下数%の分位点または当てはめた振幅から決める（最小値・最大値は雑音に引きずられるため）。 |

## 6. 操作と設定

生徒の操作は「枠を置く、測定開始、結果を見る」の3つに収める。

| ID | 要件 | 頻度 |
|---|---|---|
| POL-F-50 | 測定の開始と停止。 | 毎回 |
| POL-F-51 | 2回転を検出したら自動で停止する。M1 は印で検出する。M2 はブランクの波形が4周期進んだことで検出する（cos² の周期が180°なので、4周期がちょうど2回転）。 | 毎回 |
| POL-F-52 | 使うカメラの固定、回転の向き、ゼロ点測定の結果を保存し、次回も使う。 | 最初だけ |
| POL-F-53 | 色の選択、ガンマの係数は詳細設定に置き、通常の画面には出さない。 | 必要なとき |
| POL-F-54 | 試しに1回転させ、明るさが周期的に変わる場所を枠の候補として自動表示する。生徒はタップで役割を割り当てる。 | 将来の拡張 |

## 7. 出力

| ID | 要件 |
|---|---|
| POL-F-40 | 測定データを CSV で、グラフを画像で保存できる。 |
| POL-F-41 | フレームごとの生データを CSV で保存できる。時刻と各枠の R・G・B の平均値を、ガンマ補正前・比を取る前の値で残す。推定法の比較（POL-Q-21）と装置の検証に使う。 |

## 8. 光源ページ

光源のスマホで開く表示。測定用の端末とは別の端末で使う。

| ID | 要件 |
|---|---|
| POL-F-60 | 全画面で一様な白を表示する。ステータスバーの時計やアイコンを消す（暗い点として穴の下を横切るため）。 |
| POL-F-61 | 表示中は画面が消えないようにする（Wake Lock）。 |
| POL-F-62 | 明るさは、表示する灰色の濃さで変える。端末の画面の明るさは最大付近のまま使うよう案内する（有機ELは低輝度で点滅による調光になり、カメラにちらつきや縞が写るため）。 |
| POL-F-63 | 単色（赤・緑・青）の表示に切り替えられる（POL-F-37、POL-Q-23）。 |
| POL-F-64 | 画面の中心に十字を表示できる（回転中心と穴の位置合わせ。POL-Q-12）。測定時は消す。 |
| POL-F-65 | 自動の明るさ調整、True Tone、Night Shift などを切るよう案内する。 |

## 9. 非機能要件

| ID | 要件 |
|---|---|
| POL-N-01 | 処理はブラウザ内で完結し、映像を外部へ送信しない。 |
| POL-N-02 | センサーの許可は、ボタンのタップを起点に求める（iOS の条件）。ジャイロ方式を使わない場合は不要。 |
| POL-N-03 | 精度：M1 は cos² の形が明瞭に見えること。M2 の旋光角は ±1° を目標とし、当面の見込みは ±2° 程度とする（市販の教育用旋光計が ±1°。要検証）。誤差の主因は系統誤差と見込む（`04-polarimeter-mode.md` の10節）。 |
| POL-N-04 | タブ名やガイド文で結論を先に言わない（「cos²」や「比例」を画面の見出しに出さない）。 |
| POL-N-05 | ボタンはタブレットやスマホで押しやすい大きさにする。 |
| POL-N-06 | 近距離でレンズが自動で切り替わらないよう、使うカメラを固定できる。 |
| POL-N-07 | 遮光用の箱をかぶせて測ることを標準とする（`02-apparatus.md` の8節）。 |
