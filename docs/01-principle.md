# 原理

## 1. マリュスの法則

直線偏光を偏光板（検光子）に通すと、透過する光の強さは、偏光の向きと検光子の向きのなす角 θ で決まる。

```
I = I0 × cos²θ
```

- 偏光光源：白を表示した画面に、偏光フィルムを重ねたもの。
- 検光子：カメラに貼った偏光フィルム。
- 光源と検光子の相対的な角度だけで決まるので、どちらを回しても結果は同じである。
- 光源が一様な白なら、明るさは角度だけで決まり、位置がずれても変わらない。回転軸を厳密に出す必要はない。

### 画面だけを光源にしない理由

スマホやタブレットの画面から出る光は、機種によって偏光の種類が違う。

| 種類 | 検光子を回したとき |
|---|---|
| 直線偏光 | 明暗が出る（測定できる） |
| 円偏光 | 明るさが変わらない（測定できない） |
| ほぼ無偏光 | 明るさが変わらない（測定できない） |

画面の上に偏光フィルムを重ねれば、どの種類でも出てくる光は直線偏光になる。フィルムは光源と一緒に回るので、測定の仕組みは変わらない。背景は `02-apparatus.md` の1節を参照。

## 2. 明るさを測るときの落とし穴

### 2.1 自動露出

- 暗くなるとカメラが自動で明るくするので、そのままでは明るさの変化が消える。
- 対策：同じ画像の中に、回しても明るさが変わらない非偏光の基準領域を置き、比を取る。

```
R = （偏光の領域の明るさ）／（基準領域の明るさ）
```

- 基準の作り方：光源の偏光フィルムの上に、穴あきのコピー用紙を直接載せる。穴からは偏光が、紙を透過した部分からはほぼ非偏光の光が出る見込みである（POL-Q-01）。
- 室内光で照らした紙を基準にする方法は採らない。遮光すると室内光が届かないためである。

### 2.2 非線形性

- 画素値は光量に比例しない（ガンマ補正）。逆補正をしてから比を取る。
- 精密測光ではなく「cos² の形がはっきり見える」程度の精度と考える。

### 2.3 白飛び

- 穴の部分が白飛びすると、山がつぶれる。光源の表示を灰色に落として避ける。

## 3. 当てはめ

測定値に次の式を当てはめる。

```
I = a × cos²(θ − θ0) + b
```

- θ0：光源の偏光の向き（光源側の偏光フィルムの向き）。
- b：消光しきれない分（もれ光、ノイズ）。

## 4. 旋光

光学活性な物質の溶液を光が通ると、偏光の向きが回る。

```
α = [α] × l × c
```

- α：旋光角（度）
- [α]：比旋光度
- l：光路長（dm）
- c：濃度（g/mL）

光源と検光子の間に試料を入れると、当てはめた θ0 が α だけずれる。

### ショ糖の目安

比旋光度を +66.5（波長 589 nm、20℃）として、光路長 10 cm（1 dm）の場合。

| 濃度（g/mL） | 旋光角の目安 |
|---|---|
| 0.05 | 約 3.3° |
| 0.10 | 約 6.7° |
| 0.20 | 約 13.3° |
| 0.30 | 約 20.0° |

画面の白色光は 589 nm の単色光ではないので、実測値はこの表と一致しない。波長が短いほど旋光角は大きくなる。

## 5. 旋光分散

- 旋光角は波長で変わる。
- カメラの R・G・B を別々に解析すると、色ごとに旋光角が違うことが見える。

## 6. リサージュ図形による同時測定

ブランク（水）と試料を並べて同じ画像に写すと、どの瞬間も2つは同じ光源角度 θ を見ている。

```
ブランク：I_b ∝ cos²(θ − θ0)
試料　　：I_s ∝ cos²(θ − θ0 − α)
```

cos²x = (1 + cos 2x) / 2 なので、2つは同じ周期で振動し、位相が 2α だけずれる。

- 横軸にブランクの明るさ、縦軸に試料の明るさを取って描く。
- 旋光がなければ直線、あれば楕円になる。楕円の開き具合が位相差 2α に対応する。
- 角度 θ そのものを使わないので、回転むらや角度センサーのずれの影響を受けない。

### 読み取り方

それぞれの明るさを、自分の最小値と最大値で −1〜+1 に正規化する。

```
X = cos φ，  Y = cos(φ − δ)，  δ = 2α
X = 0 のとき  Y = ± sin δ
```

- 数値は、2つの波形にそれぞれ正弦波を当てはめて位相差から求める。リサージュ図形は見せるための表示とする。
- 右旋か左旋かは、回転台の回る向きと、楕円を回る向きの組み合わせで決まる。
- 旋光角は 180° の整数倍の違いを区別できない。濃度を変えた系列で確かめる。
