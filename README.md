# 偏光ラボ（仮称）

## 1. 概要

回転角と明るさを同時に記録し、偏光を測るアプリ。
偏光フィルムを重ねたスマホやタブレットの画面を偏光光源に、偏光フィルムを貼ったスマホのカメラを検出器にする。機材は偏光フィルム（1枚を切り分けて2か所に使う）と身近な物で足りる。

| モード | 測るもの | 分野 |
|---|---|---|
| マリュスの法則 | 回転角 θ と明るさ I の関係（cos²θ） | 物理 |
| 旋光 | ブランク（水）と試料液の同時測定による旋光角 | 化学 |

## 2. ねらい

- 回すだけで I-θ グラフがその場で描かれ、cos² の形が見える。
- カメラは画像で測るので、ブランクと試料、さらに複数の濃度を1回で同時に測れる。
- カメラの R・G・B を別々に解析し、色による旋光角の違い（旋光分散）まで扱う。

原理と個々の要素には前例がある。本アプリの位置づけは「身近な機材で、全班が同時に、複数の試料を一度に測れる」ことである（`docs/reference/prior-work.md`）。

## 3. 状態と方向性

- 構想段階（仕様 0.6）。装置を確かめるための検証キットを作った。実物での検証はこれから。
- 【決定】とした事項はまだない。以下は検討中の方向性である。
  - 平置きの配置で測る。
  - 回転台（キャンドゥのソーラー式回転台など）を使う方法を検討している。
  - ブランクと試料の同時測定を取り入れる。

## 4. 現時点で推す構成

| 項目 | 内容 |
|---|---|
| 配置 | 平置き。光源のスマホを回転台に載せて回し、測定用スマホは上に固定する（`docs/02-apparatus.md` の構成B）。 |
| 光源 | 光源のスマホでは本アプリの光源ページを開く（POL-F-60〜65）。 |
| 偏光フィルム | 光源の画面とカメラの2か所に貼る。画面の偏光の種類（直線・円・無偏光）に左右されない。 |
| 明るさ | 同じ画像内の非偏光の基準領域との比を取る。M2 で比を取るかは POL-Q-22。 |
| 角度 | マリュスの法則では画像内の印から読む。旋光では角度を測らない。 |
| 旋光角の推定 | 3つの候補を記録データで比べて決める（POL-Q-21）。 |
| ジャイロ | 使わない。カメラ側は回らないので測れず、光源側で使うには2台の間の通信が要るため。 |
| 同時測定 | 行う。ブランクと試料を同じ画像に写す。 |
| 遮光 | 段ボール箱をかぶせる。上面にカメラ用の穴を開け、測定用スマホの台を兼ねる。 |

この構成の弱点は、班ごとに端末が2台要ることである。端末が1台しかない場合や回転台が安定しない場合は、構成A（筒式、ジャイロ使用、マリュスの法則専用）が代替になる。

## 6. 引き継ぎ（次のチャットで最初にやること）

アプリの本体を作る前に、装置が成立するかを実物で確かめる。

1. 回転台の回転速度と回転むらを、phyphox のジャイロで測る（POL-Q-03）。1回目（1.2回転）は済み。周期 約17.7秒、速さは1回転の中で約2.4倍変わる。3回転以上の記録と、載せ方を変えた記録で、むらの原因を確かめる（`tools/turntable.py`）。
2. 検証キット（`docs/07-verification-kit.md`）を GitHub Pages で公開し、iPhone と Android で動くか確かめる。
3. 検証キットで、基準の紙に残る偏光を測る（POL-Q-01）。判定の目安は p/m が数%以下。露出を固定した記録で判断する。
4. 記録したデータを `tools/analyze.py` にかけ、旋光角の推定法と比の取り方を比べる（POL-Q-21・22）。
5. 結果をもとに、初版の装置構成と角度の取り方を決める（POL-Q-04）。

実物が要らない POL-Q-14（技術構成）と POL-Q-15（共通原則の適用）は、並行して決められる。

- GitHub Pages で main ブランチのルートを公開する。アプリ本体を作るときに、入口（`index.html`）を本体に差し替える。
